# 💬 클라이언트 사례: AI 뉴스챗 도입

## 🧭 Discover: 뉴스 소비 방식을 혁신하고 싶었던 클라이언트

클라이언트는 기존 뉴스 플랫폼의 한계를 다음과 같이 인식하고 있었습니다:

- 🧱 **뉴스 소비는 여전히 일방향적**: 독자는 궁금한 점이 있어도 즉시 해소할 방법이 없음
- 📉 **체류 시간, 조회수, 광고 수익 개선의 한계**
- 📲 **MZ 세대의 뉴스 소비 흐름 변화에 대한 대응 필요성**

클라이언트는 단순 기사 소비에서 벗어나, **질문 기반의 쌍방향 뉴스 소비 환경**을 만들고자 했습니다.

---

## ⚙️ Deliver: AI 기반 뉴스챗 + 멀티미디어 자동화 시스템 구축

파노믹스는 사용자의 궁금증을 중심으로 한 **AI 뉴스챗 시스템**을 설계하고 구현했습니다.

- 💬 **뉴스 기반 질의응답 시스템 개발**

  - 사용자가 기사를 읽고 궁금한 내용을 입력하면  
    → AI가 **해당 뉴스 콘텐츠만을 기반으로** 신뢰도 높은 답변 제공
  - 허위 정보나 외부 지식 오용 방지를 위한 철저한 범위 제한

- 🧲 **기사 내 유도 배너 + 작가 질문 프롬프트**

  - 기사 본문에 AI 챗 유도 배너 삽입
  - 기자가 예상 질문을 사전 설정하여 사용자 질문을 유도

- 🗣️ **AI 아나운서 및 자동 영상 생성 기능 추가**

  - 챗 결과를 뉴스 아나운서 스타일로 음성 안내
  - 관련 뉴스, 챗 응답을 바탕으로 **자동 영상 콘텐츠 생성**
  - 사용자 몰입감 향상 및 콘텐츠 다양성 확보

- 🔁 **답변에 사용된 뉴스 출처 명시**
  - 사용자가 추가 기사로 유입되도록 설계
  - **자연스러운 뉴스 순환 소비 구조 유도**
